# DUREM AI Brand

## Name

**DUREM AI**

## Tagline

**Компанийн дүрэм. Шууд хариулт.**

## Mascot

**Дүрмээ** — танигдахуйц, найрсаг хуульч нохой.

Visual cues:

- warm tan dog
- dark professional jacket
- blue-violet tie
- check/approval badge
- soft cool circular background

Mascot should feel helpful and competent, not childish. It appears on login, chat welcome, brand lockup, runtime/loading moments.

## Product personality

- trustworthy
- calm
- precise
- employee-friendly
- source-backed
- private/local

## Visual language

- dark navy navigation surfaces
- clean white/light workspace
- restrained blue-violet primary accent
- green success
- amber approval-required
- red denied/security danger
- generous whitespace
- compact enterprise data density in admin

Avoid:

- excessive gradients
- glassmorphism everywhere
- decorative motion that slows decisions
- playful copy in serious policy decisions
- visual ambiguity between allowed/denied/approval-required

## Product copy rules

Primary employee answer must surface in this order:

1. decision/state
2. direct answer/reason
3. approver if applicable
4. next steps
5. exact source
6. confidence

Never hide `NOT_FOUND` behind vague wording.
